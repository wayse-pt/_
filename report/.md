## 17. Processing of non-existent HTTP target resources
### 17.1
#### 17.1.1
If the origin server of the Lovable hosting (`p.l5e.io`) considers a non-existent target resource a file, then it returns `HTTP 404` («Not Found»).
#### 17.1.2
The origin server of the Lovable hosting qualifies a request as a file by the presence of a dot in the final path segment of the target resource URL.
### 17.2
If the origin server of the Lovable hosting does not consider a non-existent target resource a file, then it returns `HTTP 200` («OK») and the HTML skeleton **§3.2**.
### 17.2.1
For the website, the **§17.2** case is implemented, in particular, for the routes **§12.3.2**.
### 17.3
Lovable does not document the behavior **§§17.1-17.2** of the origin server of its hosting: I established this behavior empirically.
